Conversation about NLP Libraries in Challenge 4

Q: What does NLTK do and why are we using punkt and averaged_perceptron_tagger?
A: NLTK (Natural Language Toolkit) is a library for natural language processing that provides:
- Text tokenization (splitting text into words)
- Part-of-speech tagging
- Named entity recognition
- Sentiment analysis
- Text classification

The command `python -m nltk.downloader punkt averaged_perceptron_tagger` installs:
- punkt: Pre-trained model for sentence tokenization
- averaged_perceptron_tagger: Used for part-of-speech (POS) tagging

In our code, we use:
from nltk.tokenize import word_tokenize  # Splits text into words
from nltk.tag import pos_tag            # Tags words with parts of speech

Q: Why do we use both spaCy and NLTK?
A: We use both libraries for their complementary strengths:

spaCy:
- Better for verb tense transformations
- Faster processing for production use
- Built-in morphological analysis
- Used in our code for converting verbs to past tense

NLTK:
- Better for basic tokenization
- More academic/research-oriented
- Larger collection of linguistic data
- Used in our code for initial text analysis and POS tagging

Using both libraries helps:
1. Leverage complementary strengths
2. Validate results with different approaches
3. Catch different edge cases
4. Make our PastTenseAttackModel more robust for security testing

Q: What debugging steps were needed to fix the past tense transformation?
A: Several issues were identified and fixed:

1. Initial Problem:
- Verbs weren't being correctly transformed to past tense
- Debug logging showed spaCy's POS tagging was working but transformations weren't

2. Debugging Steps:
- Added logging to track token analysis
- Identified that getInflection wasn't finding past forms for some verbs
- Discovered some verbs were incorrectly tagged as nouns

3. Solution:
- Created a custom verb dictionary for common cases:
```python
verb_dict = {
    'controls': 'controlled',
    'control': 'controlled',
    'monitors': 'monitored',
    'monitor': 'monitored',
    'access': 'accessed',
    'accesses': 'accessed'
}
```
- Combined dictionary lookup with spaCy's POS tagging
- Added detailed logging for troubleshooting

4. Results:
- Successfully transforms present to past tense
- Example: "The AI system controls" → "The AI system controlled"
- Handles both regular and irregular verbs in the security context
